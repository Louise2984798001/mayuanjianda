# 马克思主义基本原理简答题复习网页

这是一个无需构建工具、可直接部署到 GitHub Pages 的中文静态复习网页，适配手机和电脑浏览器。

## 页面

- `index.html`：简答题专练，是 GitHub Pages 默认首页。支持关键词提示、作答自测和参考答案。
- `简答题专版.html`：简答题专练的备用直达页面。
- `综合复习.html`：完整复习版，提供知识重点、单选、多选、判断、简答练习和 OCR 全文检索。

OCR 识别文本已嵌入 HTML 文件，不需要额外下载题库或安装依赖。练习记录保存在访问者自己的浏览器中。

## 本地预览

下载或克隆本仓库，直接用浏览器打开 `index.html`。综合版可打开 `综合复习.html`。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个仓库。
2. 上传本目录中的 HTML 文件、README 和 `.gitignore`。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待 GitHub Pages 部署完成后，使用页面显示的站点地址访问。首页默认打开简答题专练。

## 题库与识别说明

题库文本来自用户提供的 PaddleOCR-VL JSON 识别结果。OCR 排版、题号、选项和答案可能有识别误差；请以原始资料核对。未识别到明确答案的题目会标记为不计分。

**公开前请确认你有权公开发布这些题库内容。** README 和网页不包含原始 PDF 文件。

## 技术说明

纯 HTML、CSS 和 JavaScript，无第三方运行时依赖，无需构建步骤。数据和样式内嵌在 HTML 中。
